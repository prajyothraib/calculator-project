Fun Nums Calculator

Fun Nums Calculator is a smart web-based application designed to perform multiple everyday computational tasks in one place. The platform allows users to quickly perform arithmetic calculations, convert units, convert currencies, and apply Caesar cipher encryption and decryption with an easy and interactive interface.

Project Description

This project was developed to provide a simple, fast, and reliable online tool that reduces the need for multiple separate applications. It helps students, professionals, and everyday users perform calculations efficiently anytime and anywhere.

Features

Basic arithmetic calculations such as addition, subtraction, multiplication, and division

Unit conversion between different measurement systems

Currency conversion for quick financial calculations

Caesar cipher encryption and decryption tool

Clean and responsive user interface

Instant calculation results

Technologies Used

The project is developed using HTML for structure, CSS for styling and layout design, and JavaScript for implementing calculation logic and interactivity.

How to Use

Open the application in any web browser, choose the required calculator or converter tool, enter the values, and instantly view the results on the screen.
